Command Privacy Policy

Effective November 5, 2026

This policy covers Command’s staging workspace and its TikTok Login Kit sandbox test. Command is maintained by Farhad Marjan.

Information Command handles

Cloudflare Access authenticates staging users. Command uses the verified account identifier to locate that user’s workspace. Workspace data includes information users enter or import, such as product names and prices, video titles and metrics, notes, and reminders. Command stores these records in Cloudflare D1. Cloudflare may record sign-in decisions and request information for security and troubleshooting.

TikTok Login Kit sandbox test

If the sandbox test is enabled and you choose to authorize it, Command requests TikTok’s basic profile permission (user.info.basic). The test requests only the app-specific TikTok user identifier (open_id) from the profile endpoint and checks that it matches the identifier returned during token exchange.

Command stores a single-use authorization state linked to your Command account. It expires after five minutes and is consumed on callback. Command handles the authorization code and access token on the server for the profile check. The test does not save TikTok tokens or profile identifiers in the workspace, import videos or metrics, or post to TikTok.

Use and service providers

Command uses workspace information to save and display your records. It uses sign-in and authorization data to control access, verify the sandbox integration, and troubleshoot failures. Cloudflare provides authentication, hosting and storage. TikTok handles consent, token exchange and the profile request when you choose to use Login Kit.

Retention and your choices

Workspace records remain stored until removed from the workspace or deleted by the maintainer. An expired authorization state cannot be used, although its database row may remain until it is replaced or removed. You can decline TikTok authorization and continue using Command’s manual entry and CSV features. You can manage TikTok permissions in your TikTok account settings.

Contact

For privacy questions or requests to access, correct, or delete information, open a general request in the Command issue tracker and ask for a private follow-up. The tracker is public. Keep personal information, workspace records, passwords and verification codes out of the issue.
